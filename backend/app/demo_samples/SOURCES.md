# Demo sample images

Photographs uploaded to local storage by `python -m app.demo seed` so the demo
project has real street scenes to annotate (`car`, `sign`, `pedestrian`).

All images are from Wikimedia Commons and released under **CC0 1.0** (public
domain dedication), so they can be redistributed with this repository without
attribution requirements. Authors are credited here anyway. Each file was
downscaled to a 1024 px long edge, re-encoded as JPEG, and stripped of EXIF.
